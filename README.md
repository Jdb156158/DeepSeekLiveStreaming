# DeepSeekLiveStreaming
大肥鱼 Mac 本地直播预览：扶砖小院、Live2D 角色与同页 AI 聊天。默认使用本地 Qwen，可选 DeepSeek API；尚未接入真实抖音弹幕或推流。

## 部署与接手入口

- [部署说明与部署文件清单](DEPLOYMENT.md)：新 Mac 安装、启动/停止、配置、检查及排错。
- [详细制作流程与接手指南](docs/HANDOFF.md)：从原型到当前效果的实现过程、代码职责、设计决定和后续工作。
- [智能体工作约定](AGENTS.md)：必须保留的行为与修改边界。
- [产品边界](PRODUCT.md)、[设计记录](DESIGN.md)、[验证记录](Verification/README.md)、[第三方来源](THIRD_PARTY_NOTICES.md)。

新 Apple Silicon Mac 在安装 Git / uv 后：

```sh
git clone https://github.com/Jdb156158/DeepSeekLiveStreaming.git
cd DeepSeekLiveStreaming
./scripts/setup.sh
.venv/bin/python scripts/run.py
```

当前主体验：[扶砖小院](http://127.0.0.1:18080/bricks.html)。部署入口为 `scripts/setup.sh`，依赖为 `requirements.txt`，配置示例为 `deploy/settings.example.json`。模型、第三方运行时和真实配置不在 Git 中，由下载脚本恢复；生成的场景和道具已入库。

## Mac 本地预览

双击本目录的 **启动预览.command**，或打开 <http://127.0.0.1:18080>。先点“开启声音”，再点“认识一下”或输入自己的问题。

当前可体验：

- 真实 Live2D 大肥鱼与海底场景、待机摆动和眨眼。
- 本地 Qwen2.5 0.5B 问答，无需 Key；这是轻量体验模型，不是 DeepSeek，回答能力有限。
- 晓晓在线中文配音；不可用时回退到 Mac 系统婷婷声音。
- 音频驱动口型、按音频进度粗略展开的字幕（非精确逐字对齐）。
- 朗读自定义台词、停止说话，以及单独的纯净场景 `/stage`。

这是参考大肥鱼项目制作的 Mac 本地适配。**抖音弹幕、账号和真实推流尚未接入**，不代表已开播。

页面“运行状态 → 配置 DeepSeek”可以填写自己的 API Key。Key 仅保存在本项目 `.local/settings.json`，不会回显或写入 Git。切换 DeepSeek 后，聊天内容会发送到 DeepSeek；在线配音会将待朗读文字发送到 Edge 语音服务。本地模型本身无需联网推理。

关闭页面不会结束服务。结束体验请双击 **停止预览.command**；启动脚本只启动本项目进程，不安装开机启动项。页面与模型服务分别仅监听 `127.0.0.1:18080`、`127.0.0.1:18081`。

## 重新安装环境

也可以手动创建 Python 3.11 环境，在项目目录执行：

```sh
uv venv --python 3.11 .venv
uv pip install -r requirements.txt
.venv/bin/python scripts/bootstrap.py
.venv/bin/python scripts/run.py
```

下载内容包括约 470 MB 的本地语言模型、约 33 MB 角色与运行时及 llama.cpp Mac 二进制，保存在 `.local/` 和 `web/assets/`、`web/vendor/`。这些目录不提交到 Git。下载脚本基于参考仓库固定 commit，原始模型文件保持不变；扶砖页通过模型原生参数隐藏角色身上的文字水印，画面内不显示作者署名，来源记录保留在项目文档。

素材和第三方组件来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。当前仅用于本地非商业预览。

## 扶砖互动试玩

打开 <http://127.0.0.1:18080/bricks.html>，或在聊天预览页点击“试玩扶砖”。

直播画面为暖色卡通海边小院：小屋、花树和鲸鱼浇水壶围着连续沙地；六排笑脸彩砖与角色共用画布坐标，并有地面接触阴影。原聊天预览的海底场景保持不变。背景的生成提示词和字体来源见 [web/art/README.md](web/art/README.md)。

控制台最上方“和本鱼聊聊”支持直接在小院里 AI 对话、只朗读、语音口型、字幕和停止说话，也可展开配置对话模型。发送会开启声音；聊天回复优先于扶砖固定吐槽，小院动作持续运行。暂停或重置小院不会停止聊天。顶部聊天链接只定位到本页聊天区。原海底聊天页仍保留。

“换个地方玩”提供九套背景：原海边小院、樱花庭院、蘑菇森林、糖果乐园、雪顶小镇、星光花园均保留，另新增像素·海边、像素·樱庭、像素·天台。三张像素背景采用更适合大肥鱼的蓝白/靛蓝色系，以最近邻采样保留像素边缘。点击缩略图切换，不重置当前砖块、角色任务或队列；浏览器会记住上次选择。刷新页面只恢复所选背景，游戏进度仍按原逻辑重新开始。

画面左侧设置蓝白太阳伞和浅木色小板凳。空闲时大肥鱼并膝坐着看手机；推砖后先起身，再按队列收膝半蹲扶砖，忙完走回板凳坐下。回程或坐下时收到新指令也会继续处理。九套背景共用休息角，六排砖略向右移，为休息区留出地面空间。伞与板凳由内置 imagegen 生成透明素材，提示词见 [web/art/rest-prop-prompts.json](web/art/rest-prop-prompts.json) 和 [web/art/stool-prompt.json](web/art/stool-prompt.json)；旧躺椅素材保留。

- 六排不同颜色的砖，从1号到6号依次为4、5、6、7、8、9块，前端对齐、逐排加长。点击对应号码、画面前方的号码牌，或输入“1号倒”至“6号倒”。
- 对应排依次倒下，大肥鱼移动到砖旁，脚底固定、半蹲伸手，再随砖块抬起而站起；每块动作约 1.4 秒，多排按触发顺序排队。半蹲由运行时腿部位移、重心下沉与原模型手臂参数近似表现，上身仅轻微前倾，未修改模型素材。
- 未扶完的同一排不重复入队，扶完后可再次推倒。支持暂停、继续和全部重置。
- 点击“开启声音”可以听砖块音效及角色固定短台词；配音失败不影响规则和动画。
- 背景音乐是一份 50 首的随机播放列表（`.local/fetch_bgm_kw.py` 抓取纯音乐/轻音乐，`.local/build_bgm_index.py` 生成 `web/media/bgm_kw/index.json`），其中一首是作者自己的曲子。曲目文件体积大且版权归属各自平台，不进仓库；新电脑上重跑两个脚本即可。音乐音量压低，角色说话时自动降得更低。
- 规则完全由本地代码执行，不等待大模型，不涉及礼物。输入目前仅在该试玩页内生效，尚未接入真实抖音弹幕或跨窗口场景同步。
- 角色使用现有 Live2D 模型、程序化半蹲与原生手臂参数，没有新增作者制作的走路或扶砖骨骼动画。角色身上的文字水印使用原生 `Paramcol_3` 参数隐藏，作者署名保留在项目文档，不在扶砖画面显示。

规则回归测试在 `tests/domino-engine.test.mjs`，执行 `node tests/run.mjs`，当前15项检查覆盖长短砖排、指令、连倒、扶起时序、姿态几何、重复任务、排队、暂停和重置。Node.js 仅用于测试，不是运行服务的依赖。
