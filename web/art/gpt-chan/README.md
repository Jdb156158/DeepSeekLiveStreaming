# GPT 娘立绘（ChatGPT 娘）

扶砖小院背景里站在 Gemini 娘右侧的角色。

## 来源

- 角色：**GPT 娘 / ChatGPT 娘**，白发、龙角、龙翼、龙尾，白金礼服的「御姐白龙」龙娘设定，形象创作者 **ZipZipPipe**。
- 图片：来自 [genderswapai.com「GPT 娘」角色档案页](https://genderswapai.com/zh-CN/ai-gijinka/gpt) 的「角色三视图 PNG」（`/images/ai-gijinka-turnarounds/gpt.png`，正面／侧面／背面）。
- 本项目只裁切了**正面视图**，并从画布边缘做泛洪填充把白底透明化，人物本身未改动。

## 处理说明

这张立绘是白发白裙，直接按亮度抠白底会把裙子抠出洞。因此改用**从画布四边向内泛洪填充**只去掉与边框连通的白底，裙内高光保留。裁切后为 537×1004。

## 播放方式

单张立绘，由代码驱动：轻微呼吸起伏、缓慢左右摇摆和上下浮动，脚下有接触阴影。与 Gemini 娘共用同一排和同一地面线，起始相位错开，不会同步摆动。
