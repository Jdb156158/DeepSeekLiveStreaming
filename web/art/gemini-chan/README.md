# Gemini 娘立绘

扶砖小院背景里站在克劳德娘右侧的角色。

## 来源

- 角色：**Gemini 娘**，蓝紫色长发、蓝紫猫耳、异色瞳、星形发饰的猫娘设定，形象创作者 **ZipZipPipe**。
- 图片：来自 [genderswapai.com「Gemini 娘」角色档案页](https://genderswapai.com/zh-CN/ai-gijinka/gemini) 提供的「角色三视图 PNG」（`/images/ai-gijinka-turnarounds/gemini.png`，正面／侧面／背面）。
- 本项目只裁切了其中的**正面视图**，并把白色背景处理为透明（`gemini-stand.webp`），人物本身未改动。

该站点对这张立绘的说明是「**ZipZipPipe 立绘的使用条件另按原帖确认**」。也就是说：

- 这张立绘**没有**像 CrossPet 那样附带的 CC BY-NC-SA 4.0 等明确协议。
- 本项目按**个人本地非商业预览**使用，并保留作者 ZipZipPipe 署名。
- 若要公开直播、发布或用于任何商业用途，需先取得 ZipZipPipe 本人的许可（可在其 B 站主页确认）。
- 「Gemini」是 Google 的商标，此为社区二创角色，与 Google 无关。

如果要换成许可更明确的素材，备选是 CrossPet 的 Gemini 娘（CC BY-NC-SA 4.0），但那是 Q 版画风，与本立绘不一致。

## 播放方式

单张立绘，由代码驱动：轻微呼吸起伏、缓慢左右摇摆（skew）和上下浮动，脚下有接触阴影。不会说话，不参与推砖和扶砖。
