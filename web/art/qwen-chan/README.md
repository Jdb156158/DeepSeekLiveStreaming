## 处理说明

立绘是白裙配蓝紫外袍，因此同样采用**从画布四边向内泛洪填充**的方式去白底，避免把裙子高光抠出洞。裁切后为 515×982。

## 播放方式

单张立绘，由代码驱动：轻微呼吸起伏、缓慢左右摇摆和上下浮动，脚下有接触阴影。与 Gemini 娘、GPT 娘共用同一排和同一地面线，起始相位各自错开。
